# AT32 Workbench and BSP-owned I2C

The 20Wh platform uses **I2C1 master interrupts** for SW6306, SC7A20 and
SD3078. The original Artery Technology `i2c_application.c` included slave,
DMA and SMBus paths not used by this project.

## Ownership

- `Bootstrap/src/bsp_i2c.c` owns the subset of master TX/RX, memory-register
  accesses, interrupt dispatch and transaction retry/recovery. It retains the
  original Artery 2025 copyright attribution and project bugfixes.
- `Bootstrap/inc/bsp_i2c.h` owns the handle/status types, while
  `Bootstrap/inc/i2c_application.h` only redirects generated includes.
- Generated `project/src/main.c` still calls `wk_i2c_app_init()`. The symbol
  now belongs to BSP and initializes `hi2c1.i2cx = I2C1`.
- Generated `project/src/at32f423_int.c` calls the BSP-owned
  `i2c_evt_irq_handler()` / `i2c_err_irq_handler()`, preserving its own
  user-code notification blocks. The BSP ISR abort path closes all transaction
  interrupts and prevents pcount/psize underflow even if Workbench regenerates
  its vendor middleware.
- `project/src/i2c_app.c` and vendor `middlewares/i2c_application_library/`
  may be regenerated by Workbench; neither is compiled in Keil.

## When changing pins or clocks with AT32 Workbench

1. Regenerate the Workbench project normally, preserving its `add user code`
   sections. Keep `I2C1` peripheral enabled and its IRQ handlers generated.
2. From the repo root, run
   `python firmware/tools/restore_workbench_project.py`.
3. Run `python firmware/tools/restore_workbench_project.py --check`.
   The script is idempotent and restores the maintained Keil source list.
4. Build with Keil, checking that `bsp_i2c.c` is compiled exactly once and
   `i2c_application.c`/`i2c_app.c` are not compiled. Confirm the regenerated
   event/error IRQ wrappers still notify `i2c_wait_task`.
5. Test register reads, writes, bus recovery, lost-ACK and repeated resets
   on actual hardware before relying on the migrated driver.

**Important:** Workbench might overwrite its own generated
`Pocket_PowerBank.uvprojx`. Reapplying the checked-in script is required; the
script does not change Workbench's peripheral settings. The original vendor
library is retained in the repository only as a reference/regeneration input.
